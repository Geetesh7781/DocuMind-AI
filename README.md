# DocuMind AI – RAG-Based Intelligent Document Assistant

Upload PDFs and ask questions in plain language. Answers are generated by an LLM from the
most relevant passages only, and every claim carries a clickable citation (file + page).

## Architecture

```
PDF ─► pypdf extraction ─► page-aware chunking (180 words, 40 overlap)
    ─► MiniLM embeddings ─► ChromaDB (cosine)
Question ─► embed ─► top-k retrieval ─► grounded prompt ─► LLM ─► answer + [n] citations
React UI ◄──── REST (FastAPI) ────►
```

## Run it

Backend (Python 3.10+):
```bash
cd backend
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # add your API key (or set LLM_PROVIDER=none)
uvicorn app.main:app --reload --port 8000
```

Frontend (Node 18+):
```bash
cd frontend
npm install
npm run dev                 # http://localhost:5173
```

API docs: http://localhost:8000/docs · Tests: `cd backend && pytest`

## API

| Method | Route | Purpose |
|---|---|---|
| POST | /api/documents | Upload + index a PDF |
| GET | /api/documents | List indexed documents |
| DELETE | /api/documents/{id} | Remove a document |
| POST | /api/chat | Ask a question, optionally scoped to `doc_ids` |
| GET | /api/health | Status |

## Design decisions

- **Page-bounded chunks** so each citation points to exactly one page.
- **Grounded prompt**: the model must cite passage numbers and admit when the answer is absent.
- **Provider-agnostic LLM layer** (`llm.py`): Anthropic, OpenAI, or retrieval-only mode.
- **Local embeddings**: no embedding API cost; documents never leave your machine except the top passages sent to the LLM.

## Roadmap

OCR for scanned PDFs, hybrid BM25 + vector search, re-ranking, streaming answers, auth + per-user collections.
